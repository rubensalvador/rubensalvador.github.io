# Site modifications to the al-folio v1.2 starter

Everything this site changes relative to a fresh al-folio v1.2 starter, why, what it does, and what could go wrong.
Keep this file up to date with every change to theme behaviour, configuration or tooling (content edits such as news or bib entries don't need an entry).

- **Baseline:** commit `3c61dfd` = pristine `alshedivat/al-folio` tag `v1.2` (2026-08-09). The full list of changes is always `git diff --stat 3c61dfd HEAD`.
- **Theme:** gems pinned in `Gemfile` (`al_folio_core` 1.0.15, `al_folio_cv` 1.0.2, …). No theme file is edited in place; the theme can only be changed through the points below.
- **Audit (2026-11-25):** `bundle exec al-folio upgrade audit` passes with 0 blocking issues; `overrides audit` reports the single override below.

## 4. Pages and content

Content, not theme: listed so that a fresh start can be reproduced.

- **Removed starter demo content:** demo posts, projects, news, books, teachings, blog/repositories/plugins/dropdown pages, demo assets (audio, video, plotly, jupyter, rendercv, JSON resume), `docs/`, `test/`, `readme_preview/`, `lighthouse_results/`, AI-agent instruction files.
- `_pages/about.md`: title, subtitle, bio, office address, `latest_posts` disabled (no blog), announcements = `_news/`.
- `_pages/cv.md`: first in the navbar, PDF button → `assets/pdf/cv_rsalvador.pdf` (from `make webcv`), empty description; HTML CV from `_data/cv.yml` (RenderCV format, upstream default).
- `_pages/publications.md`: title/description, plus T4.
- `_pages/research.md` (new): research statement, navbar dropdown with "My research" and "Projects".
- `_pages/projects.md`: not in the navbar (reached through the Research dropdown), categories `current`/`past`, "Work In Progress" banner. `nav_order:` is left empty (harmless).
- `_pages/profiles.md` (People): placeholder profiles commented out, `profiles: []` (empty page, still in the navbar).
- `_pages/teaching.md`: v1.2 starter page (text, course collection `_teachings/`, empty for now), with the title capitalised and `nav_order: 4`; the starter demo Google Calendar (`test@gmail.com`) is commented out with `{% comment %}` until there is a real calendar.
- `_pages/about_einstein.md`: pristine starter file (used only by the commented-out People placeholder).
- `_news/` (7 items), `_projects/ATTILA.md`, `_data/socials.yml`, `_bibliography/papers.bib` (generated by `make website` from the curriculum, never edited here), images and PDFs in `assets/`.
